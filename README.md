# Shrinika Travels — Next.js Web Application

Shrinika Travels is a premier taxi rental, homestay, and travel booking service platform in India, serving coastal Karnataka, Maharashtra, outstation routes, and airport transfers.

## Features

- **Cab Booking Flow**: Select pickup, destination (with intelligent autocomplete), date, time, vehicle, and passenger count with instant WhatsApp confirmation.
- **Fleet Showcase**: Comprehensive specifications, pricing, and features for sedans, MPVs, and SUVs (Dzire, Etios, Ertiga, Innova Crysta, XUV700).
- **Stays & Rentals**: Homestay and furnished rented house booking inquiries.
- **Modern Architecture**: Next.js 15 App Router, React 19, TypeScript, and Tailwind CSS v4.

## Getting Started

### Prerequisites

- Node.js (v18.18+ or v20+)
- npm

### Installation & Run

1. Clone or open the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Scripts

- `npm run dev`: Starts the Next.js development server on port 3000.
- `npm run build`: Builds the production bundle in `.next/`.
- `npm run start`: Runs the production server on port 3000.
- `npm run lint`: Runs TypeScript type checking (`tsc --noEmit`).
